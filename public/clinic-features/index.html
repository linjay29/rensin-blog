診療設備

檢查與治療，由醫師評估後安排

我們不提供指定項目的檢查。X 光、超音波要不要做、做哪個部位，由醫師依當次的病情判斷。

是否符合健保的規定，也由病情決定——符合的依健保申報，不符合的部分為自費，做之前一定先說明內容與費用。

電話裡無法判斷病情，所以無法在電話中回答你的狀況能不能用健保，請直接掛號由醫師評估。

檢查

數位 X 光

拍完幾秒鐘影像就出現在螢幕上，醫師可以當場放大、跟你一起看。 主要看骨頭的排列、骨折、關節間隙與退化的變化。 拍攝時只要按指示擺好姿勢，過程不會痛，幾分鐘就結束。

肌肉骨骼超音波

沒有輻射，看的是 X 光看不到的東西：肌腱、韌帶、肌肉與周邊神經。 最大的好處是它會動——一邊請你活動關節，一邊看組織在動作中的變化，這是靜態影像看不到的。 檢查時在皮膚塗上凝膠，探頭貼著移動，大部分情況不會痛。

治療

藥物與物理治療

急性期先把發炎與疼痛壓下來，讓你能正常過日子。 三樓復健室由物理治療師執行，儀器治療與徒手治療並用。 骨骼肌肉的問題需要時間恢復，持續治療才是改善的方法——這也是我們會先跟你確認時間排得出來才安排療程的原因。

超音波導引注射

在超音波底下邊看邊打，針尖位置與周邊的神經血管都看得見，有助於提升注射的定位準確性。 使用的項目包括自體骨髓、PRP 自體血小板、增生治療、神經解套與玻尿酸，由醫師親自執行。 注射前會先說明要打的是什麼、為什麼打在這裡。

體外震波

把聲波能量從體表送進深層組織，不用開刀、不用麻醉，做完直接回家。 單次十幾分鐘，通常安排數次為一個療程。 過程中會有痠脹感，強度會依你的耐受度調整，不必忍。

高能量雷射

用在疼痛與發炎的部位，單次療程短、不需要恢復期，做完可以照常活動。 常在症狀較嚴重，或希望復原快一點的時候搭配使用。

我們的做法

  • 先診斷，再治療——弄清楚是什麼，再決定做什麼。
  • 該用健保就用健保——在合理的前提下，先用健保能做的方式治療；健保做不到、或健保的方式治不好，才會告訴你有哪些自費的選項。
  • 給建議，讓你選擇——不會強迫推銷，也沒有非做不可的療程。自費項目的內容與費用，進行前一定先說明。
  • 不是骨科的範圍會轉介——有些問題不在這裡解決，我們會告訴你該找誰。

以上為一般性說明，僅供了解各項檢查與治療的原理與過程，不能取代醫師的診察與判斷。 是否適用、療程次數與費用，須由醫師當面評估後決定；部分項目為自費，進行前會先向你說明。
